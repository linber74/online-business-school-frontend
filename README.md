# Online Business School: Frontend

Frontend for the Online Business School, an online school with live and
recorded lectures. Built by the LIA student team for Via Mare Consulting.

> Status: early development. This repository is temporary and will be moved.

## Tech
- React + TypeScript
- Vite

## Getting started
1. Clone the repository `git clone <repository-url>`
2. Install dependencies: `npm install`
3. Start the dev server: `npm run dev`
4. Open http://localhost:5173

## Project structure
```
src/
  components/   Reusable parts (Header, Card)
  pages/        Pages (Home)
```

## Workflow
- One branch per task, named feature/..., fix/... or docs/...
- Open a pull request to main when the task is done
